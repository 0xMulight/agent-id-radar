# Agent ID Radar · 沐光个人版

**沿用 Agent ID Sniper v2.8.2 完整引擎，增加个人配置。** 保留链上扫描、TG 群／重点群、热门网址、跟单适配、USDT 换币、多钱包、开池检查和持仓管理。项目不再需要预先填写审核模板。

固定来源为 [nancyc0813-maker/agentid-sniper · ef74121](https://github.com/nancyc0813-maker/agentid-sniper/tree/ef741211780bacec8ccbbc25b3f7449cc84bc3e2)。原始源码和完整说明保存在 [vendor/agentid-sniper](vendor/agentid-sniper)。这是独立衍生版本，不是原作者发布。

## 默认规则

| 项目 | 设置 |
| --- | --- |
| 发现与进场 | 保留上游链上、TG、网址发现及进场检查，不加逐项目审核模板 |
| 退款 | 不作为必要条件，提示“未核实，按非保本参与” |
| 付费 NFT | 保留参与入口，沿用上游 NFT 检查；每钱包每项目累计 5U |
| 普通项目 | 每钱包每项目累计 12U，包含付款和已确认 Gas |
| 新参与日预算 | 所有钱包合计 0.05 BNB 等值，北京时间自然日 |
| 自动 Gas 日额度 | 所有自动操作合计 0.01 BNB；买入额度用完后卖出／撤销仍可使用此额度 |
| 单笔 Gas 预留 | 广播前预占 0.001 BNB，确认后按回执记账；这不是 SDK 签名费用的硬上限 |
| 钱包保留 | 新参与后保留 0.006 BNB |
| 回本与长抱 | 2 倍开始尝试回收成本，记录净收入覆盖成本后，保留此后剩余数量的 20% |
| 回撤 | 付费币回本前 40%、回本后 60%；普通退出不动长抱部分 |
| 免费项目 | 沿用上游：免费打新只提醒，不自动铸造；免费代币退出沿用上游，不再使用旧版 30% 底仓 |

20% 指回本后剩余数量。例如忽略费用，100 枚卖掉 50 枚回本后，保留剩余 50 枚中的 10 枚。明确的 TG 全卖指令可以包含长抱部分。

加价金额全部计入预算，没有豁免。BNB 换 USDT 先预占资金，确认到账后只记录价差及 Gas，后续铸造再计 USDT 付款，避免把同一笔本金算两遍。未确认请求跨日和重启继续占用预算。

## Windows 使用

需要 Node.js 22 或更高版本。下载 ZIP，**解压到新目录**：

1. 双击 **一键安装.bat**，安装官方钱包 CLI 并填写自己的 .ai 名称、地址、可选 TG 通知。安装器固定 CLI 1.12.0；已有其他版本可在钱包配置的 bawModule 中指定其 JS 入口。
2. 双击 **登录钱包.bat**，在自己的币安 App 完成登录。第二个钱包使用 setup_wallet2.bat。
3. 需要 TG 群和热门网址发现时，双击 **tg_login.bat**，完成自己的 TG 登录。重点群在 data/tg_vip.txt 中一行写一个群名关键词。
4. 先双击 **双击启动观察.bat**。完整发现与预演继续运行，交易发送被拦截；观察状态独立保存，不会被当成真实成交。
5. 核对钱包和预算、关闭观察窗口后，再双击 **双击启动交易.bat**。这个入口会设置 live 并传入 --execute，之后可能真实花费钱包资金。

安装器不会自动开启交易或创建开机交易任务。观察模式未安装 CLI／未登录时，相关预演可能失败。关闭窗口可停止；也可建立 WATCH_STOP 文件，重启前需手动移除。

TG 仍支持余额、持仓、战绩和卖出指令。私人聊天只接受所属用户；通知目标为群时，须设置 telegram.controlUserId 为自己的用户 ID 才接受控制。群信息发现不授予群成员控制权。

## 订单与状态

拿到 orderId 仅表示提交，本版会等到市场订单终态并核对回执。待 App 确认、超时、部分成交、缺少收入字段或数量不符时，不报告整笔成功，也不把它当作回本。

双击 **查看订单状态.bat** 查看记录。unknown／broadcasting／reserved 持续占用钱包和预算；先到官方钱包核对，再人工处理日记与上游仓位。**不要删除 data 解锁。** 本版没有完整的历史持仓迁移或未知订单自动修复功能。

## 验证与更新

~~~sh
npm run check
npm test
npm run build
~~~

检查不调用钱包、不联网交易。原始引擎固定哈希，根目录 watch.mjs 由 [补丁清单](personal/patches.json) 重现生成。上游覆盖更新已停用；后续需固定新提交、检查差异并重新验证，再发布个人版。

**此次开发没有安装 SDK、登录账户或执行真实交易；真实钱包兼容、Windows 启动和智能账户回执仍需验证。** 离线测试不证明收益或卖出成功率。上游 NFT 成交量提醒不等于 NFT 自动挂单／卖出；第三方展示价不等于可成交净收入。更多边界见 [SECURITY.md](SECURITY.md)。

旧审核模板版保留在 [archive/guarded-beta2](https://github.com/0xMulight/agent-id-radar/tree/archive/guarded-beta2)。旧配置和 guard-state.json 不可复制到本版；旧版的 75 项测试也不代表本版通过同样验证。
